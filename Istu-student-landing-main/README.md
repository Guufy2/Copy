# Сайт-справка для студентов

Nuxt 4, Vue 3, TypeScript, Tailwind CSS 4, ESLint и Prettier. Статьи и разделы хранятся в Directus 11.17.4. Сохранены палитра, стеклянные поверхности и непрерывный фон предоставленного макета. Поиск пока не реализован.

## Локальный запуск

Нужны Node.js 24.15+ и Docker с Compose. Версия Node указана в `.nvmrc`; пакет `node` также закреплён в devDependencies, поэтому npm-команды проекта используют совместимую локальную версию, не меняя системный Node.

```sh
npm ci
npm run cms:init-env
npm run cms:up
npm run cms:setup
npm run dev
```

- Сайт: http://127.0.0.1:3000
- Directus: http://127.0.0.1:8055
- Логин и случайный пароль администратора: `DIRECTUS_ADMIN_EMAIL` и `DIRECTUS_ADMIN_PASSWORD` в локальном `.env`.

`cms:init-env` создаёт `.env` с правами 0600 и не перезаписывает существующий файл. Не добавляйте его в Git. `cms:setup` создаёт коллекции, связь статьи с разделом, публичную политику чтения опубликованных статей и демонстрационные материалы. Повторный запуск добавляет недостающие записи по slug, сохраняя изменения редакторов. Пароль из `.env` применяется Directus при первой инициализации; изменение файла не меняет пароль существующего пользователя.

## Редактирование статей

В Directus откройте «Разделы» и «Статьи». Для статьи задайте уникальный `slug` латиницей с дефисами, заголовок, описание, раздел и текст в визуальном редакторе. Заголовки h2/h3 формируют оглавление. `featured` выводит статью на главной, `is_faq` добавляет её в частые вопросы, `reading_minutes` задаёт время чтения, `sort` — порядок.

Новые статьи создаются со статусом `draft`. На сайте и через публичный API видны только статьи со статусом `published`. Публичная политика не разрешает запись. HTML очищается на сервере по списку разрешённых тегов; скрипты, обработчики событий и опасные ссылки удаляются.

Материалы из примера отмечены `is_demo` и сопровождаются предупреждением на сайте. Кроме примера академического отпуска, статьи содержат заглушки для редактора. Перед реальным использованием замените тексты проверенными сведениями и снимите `is_demo`. Это не официальная база университета.

## Страницы и исходники

- `/` — главная, `/catalog` — каталог с фильтром по разделам.
- `/sections`, `/sections/:slug` — разделы и их статьи.
- `/articles/:slug` — статья с навигацией и оглавлением.
- `/faq` — вопросы с фильтром; `/search` — сообщение о недоступности поиска.
- Старые `.html`-адреса перенаправляются на соответствующие страницы Nuxt.
- `app/` — Vue-компоненты, страницы и composables. Все стили интерфейса записаны utility-классами Tailwind прямо в Vue-шаблонах, включая фон, стеклянные эффекты, состояния фокуса и существующие адаптивные правила. `app/assets/css/main.css` содержит только импорт Tailwind и настройку шрифта; пользовательских CSS-селекторов, `@apply`, `<style>` и inline-стилей нет. Текст статей из CMS оформляется Tailwind-вариантами на контейнере. Цвета категорий заданы полными utility-классами в `app/utils/categoryTone.ts`, чтобы они попадали в сборку.
- `server/` — серверные запросы к Directus и очистка HTML; `shared/types/` — общие типы.
- `directus/` — воспроизводимая схема и демонстрационный контент; `scripts/` — настройка CMS.
- `design/references/` — визуальные референсы. Устаревшие HTML-файлы и каталог `design/legacy/` удалены. CSS в корне остался от прототипа и не используется приложением.

Состояния загрузки, пустого результата и недоступности CMS предусмотрены. При недоступной CMS сайт сообщает об ошибке и предлагает повторить запрос, не подменяя содержимое локальными данными.

## Проверки и сборка

```sh
npm run check       # ESLint, Prettier, TypeScript
npm test            # очистка HTML и оглавление
npm run test:integration # с запущенными Nuxt и Directus
npm run build       # production-сборка
npm run preview     # просмотр сборки
```

`npm run format` форматирует исходники, `npm run lint:fix` исправляет замечания ESLint. Исходные макеты исключены из форматирования.

## Данные и остановка

```sh
npm run cms:down
```

База SQLite и загруженные файлы сохраняются в именованных Docker-томах. Не удаляйте тома при обычной остановке. Для резервной копии остановите CMS и сохраните оба тома `istu-student-help_directus11_database` и `istu-student-help_directus11_uploads`.

Для другого Directus укажите его URL в `NUXT_DIRECTUS_URL` (серверная настройка Nuxt) и `DIRECTUS_URL` (скрипт настройки). Браузер обращается только к API Nuxt. Внешний хостинг и production-развёртывание в этой задаче не настроены.

Интеграция Tailwind соответствует [официальной инструкции для Nuxt](https://tailwindcss.com/docs/installation/framework-guides/nuxt); доступ к контенту — модели [политик Directus](https://directus.com/docs/guides/auth/access-control).

Directus закреплён на 11.17.4: фильтр публичного доступа по статусу работает без ключа Directus 12. Не обновляйте образ на 12 без предварительной проверки лицензии и политик доступа.

Интеграционная проверка создаёт временную статью, проверяет закрытость черновика, публикацию и запрет анонимной записи, затем удаляет только собственную тестовую запись.
